\# 中国象棋联机版



简介：

&nbsp;	本代码是基于java的简单中国象棋游戏实现，包含单机和联机功能，在联机模式中，对弈双方可以发送信息聊天或按住按钮语音聊天，可进行悔棋或重开等操作；主要代码在./src/Experiment/下,代码测试时java版本为‘25’



程序运行方式：

&nbsp;	1.  在终端中打开./src/，先编译源代码，以本机为例："> javac .\\Experiment\\\*.java"

&nbsp;	   2. 选择运行单机或联机版本，单机源代码为"GameMain.java"，联机源代码为"GameLauncher.java"，以联机版为例：

&nbsp;         "> java Experiment.GameLauncher"，弹出窗口中选择启动服务器端或客户端，服务器端启动时若没有链接将没有画面显示，当某一客户端输入ip链接成功后双方将进入游戏画面，执子显示在游戏窗口左上角；本游戏不支持2个客户端以上链接同一个服务端

&nbsp;	3. 点击窗口右上角按钮退出游戏，任意一方因此断开连接后另一方都将无法继续游戏



注意：

&nbsp;	由于本代码测试时间、测试次数过少，且部分漏洞查找和优化工作由AI完成，故可能会出现未知bug，请见谅
